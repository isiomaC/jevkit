# Changelog

All notable changes to JevKit are documented here.

## Unreleased

- Initial native Swift Package Manager implementation for TypeSafe Jev.

## Release policy

`v0.1.0` will be tagged only after the package passes its deterministic suite
and the CLI completes one opt-in live Jev call using a host-supplied API key.
